Run the scientific experiments

Use Python 3.11.15 with the locked environment:

    uv sync --frozen --extra notebook
Inputs

Extract Simulation_Inputs.zip from the matching data deposit at the repository
root. It supplies the exact observation files, weather and building models used
by this workflow. Retain the data/ directory structure.

Download Simulation_Inputs.zip from the associated Figshare dataset. Place it
beside pyproject.toml and extract it at the code repository root. In PowerShell:

    Expand-Archive -LiteralPath .\Simulation_Inputs.zip -DestinationPath . -Force

The source locations and versions are recorded in data/metadata/source_manifest.csv,
data/metadata/ctcd_bundle_source.json and
data/metadata/global_fixed_reference_weather_sources.csv. Required files are
listed in src/utilities/audit_reproduction_inputs.py. The archive already places
the observations in data/upstream/, the nine EPW files in
data/upstream/global_climate_matrix/weather/, and the prepared reference in
data/upstream/frozen_buildings/Miami/baseline.idf. Use these supplied files;
no additional model download or reference preparation is needed.

Install the complete EnergyPlus 22.1.0 Windows distribution, build ed759b17ee,
at tools/EnergyPlus-22.1.0/. Scientific inputs and retained outputs remain
inside the project; the program may create its own temporary working directory.
Run

Inspect the workflow without running simulations:

    uv run --frozen python reproduce_from_raw.py --output-root output/new_run --plan

Run all stages:

    uv run --frozen python reproduce_from_raw.py --output-root output/new_run --workers 6

The stages reconstruct demand, analyze observations, generate annual candidates,
and evaluate seasonal commands, spatial arrangements, equipment and response
operations. Paired service-limit sensitivity uses the completed candidate
library and retained temperature trajectories. Use a new output directory for
a new demand reconstruction.
The workflow also evaluates additional sampled demand compositions using the
31 shared commands in each weather context and compares the final operation
library with its 21–26 °C command subset. These analyses supply Fig. S3.
The complete workflow requires at least 250 GiB free space at startup.
Fixed seeds, partitions, grids, service budgets and numerical criteria are in
data/metadata/strengthening_protocol/. Third-party inputs retain their original
terms, recorded in THIRD_PARTY_NOTICES.txt.
