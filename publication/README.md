# Retained scientific and plotting modules

These paths preserve the verified numerical and graphical implementation. They contain no manuscript drafts, Word templates or document builders.

Use `python ctl/reproduce.py` from the repository root for the complete scientific replay. `reproduce_publication.py` rebuilds supporting human and historical-library analyses. `reproduce_energy_service.py` computes actual three-control comparisons. `reproduce_energy_service_publication.py` combines both sets with the current 27 figures and source-data exports. Its historical filename preserves module paths; its execution is entirely scientific.

`energy_service/` contains service, annual/event selection, control generation, room compatibility, permission, spatial, portfolio and cost methods. `energy_service_paper/scripts/` contains current figure renderers and asset assembly. `scripts/` supplies supporting renderers and geometry checks. `experiments/` contains candidate-support, protected-rule, management and source-building sensitivity calculations. Reference JSON files are bibliographic metadata only.

`support/MANIFEST.json` binds small aggregate tables used by supporting plots. These include demographic summaries, variance checks, whole-city holdout diagnostics and frozen candidate references. Their presence does not mean upstream records, spatial models or historical action generators are recreated here. Recalculated decision products are checked against retained references only after calculation. Hourly trajectories are supplied separately.

Historical panel identifiers remain stable for checksums. Current figure numbering and exact input routes appear in the generated figure-source map. Fonts, graphical products and numerical output directories are excluded from Git.
